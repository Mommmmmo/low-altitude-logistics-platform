# 贵州枢纽 · 低空智慧物流平台

一个面向低空经济场景的智慧物流平台前端演示项目，围绕无人机配送的完整业务链路，覆盖商家、飞手、客户、运营四类角色的核心流程。

> 纯原生单文件实现（HTML + CSS + JavaScript），无需构建、无需安装依赖，打开即用。

## ✨ 功能总览

平台通过顶部角色标签切换四端视图，每端包含独立的侧边栏导航与功能页面：

| 角色 | 功能模块 |
|------|----------|
| 🏪 **商家端** | 数据看板 · 下单管理（支持批量下单 / Excel 导入）· 全链路追踪 · 对账结算 |
| 🚁 **飞手端** | 抢单大厅（支持应急快单）· 航线导航 · 收益明细与提现 · 资质管理 |
| 📦 **客户端** | 扫码查件（摄像头扫码）· 实时轨迹查询 · 收货确认 · 售后理赔 |
| 🗺️ **运营端** | 全域调度大屏 · 航线空域管理 · 准入合规 · 财务结算 · 纠纷仲裁 · 数据统计 |

## 🗺️ 地图能力

- 集成 **高德地图（AMap）** API，用于全链路追踪、航线导航与实时轨迹展示
- 右上角「地图 Key 配置」支持双 Key 配置（Key + 安全密钥），适配高德 2021 年后申请 Key 的安全校验要求

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/Mommmmmo/low-altitude-logistics-platform.git

# 2. 直接用浏览器打开 index.html 即可
```

无任何构建步骤与外部依赖。如需使用地图相关页面，请先在页面右上角「地图 Key 配置」中填入你自己的高德开放平台 Key。

## 🛠️ 技术要点

- **单文件架构**：结构、样式、逻辑全部内聚于 `index.html`，便于评审与演示
- **角色驱动路由**：基于 `roles` 配置对象动态渲染侧边栏菜单与页面视图，新增模块只需追加配置
- **CSS 设计系统**：通过 CSS 变量统一色彩、圆角、阴影，白底极简商业风格
- **内联 SVG 图标**：无外部图标库依赖
